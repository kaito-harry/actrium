Actrium V1：从邀请加入 Realm 到启动程序的完整流程

基于三个域名，展示 Realm 创建、邀请兑换、客户端启用与服务端部署的完整流程。

域名与角色

publisher.example
Publisher：发布 package 与 Publisher Profile
提供 echo.actr、echo-worker.actr
realm.example
Realm：应用实例域名
签署 Realm Profile，提供邀请与入口 URI
realm-infra-provider.example
Realm Infra Provider：基础设施提供方
提供 Issuer、Signaling、STUN/TURN

主流程（7 步）

  1. 发布程序：在 publisher.example 发布 .actr 包

  2. 创建 Realm：创建实例并签署 Realm Profile
    配置 package 与受信基础设施

  3. 邀请成员：生成 invite（realm id、secret）

  4. 兑换加入：验证 Profile，兑换并登记成员

  5. 打开实例：加入成功后使用 Realm URI

  6. 连接与 Attach：双向认证并建立 Session

  7. 启动程序：加载 Guest，完成首次 RPC

客户端详细步骤（从加入到启动）

  1. 收到邀请：Owner 提供 invite
    包含 realm id 与一次性 secret

  2. 兑换加入：先验证 Realm Profile
    用设备 key 兑换 invite，登记 Member / Device

  3. 打开 URI：加入成功后打开实例
    actr://realm.example/<realm-id>

  4. 验证 Realm Profile
    核对签名、sequence、状态与 Provider

  5. 验证 Publisher Profile 与 root package
    校验 sha256、manifest 签名，准备 Guest

  6. Front 注册身份，建立 WSS + ICE 连接
    完成双向认证 Attach，取得 Session

  7. 启动程序：加载已验证的 Guest
    发起业务 RPC，检查 Echo 返回结果

服务端详细步骤（部署与运行）

  1. Service Host 以获准身份加入 Realm。

  2. 下载 .actr，验证摘要、发布者签名、类型及运行要求。

  3. 准备包路径、公钥、Realm 身份，
    以及 Issuer / Signaling / ICE 等运行配置。

  4. 向 Issuer 注册，取得 ActorId 和 credential，
    启动 workload 并接入信令。

启动命令 
actr run -c service-actr.toml --hyper-dir ./state/service
