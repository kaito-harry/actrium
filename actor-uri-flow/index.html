Actrium | 从 Actor URI 发现、下载并验证 .actr 启动（方案 A：Realm 自行托管 Realm Profile）

基于 GitHub actrium/actrium 的协议设计（v1）

Publisher（发布者）— publisher.example

提供 Package（.actr）发布、版本管理与签名公钥，供客户端下载与完整性验证。

Realm（领域）— realm.example

作为命名空间与信任域，提供 Authority Discovery（.well-known/actr）与 Realm 服务入口。

Realm Infra Provider（领域基础设施）— realm-infra-provider.example

托管并提供 Issuer、Signaling、TURN 等运行时服务能力。

① URI 解析

定位 Realm 与 Actor

1

用户打开 Actor URI:

actr://realm.example/k7m2q9xh
  • 解析得到：Realm ID = k7m2q9xh
  • 当前领域（Realm）= k7m2q9xh@realm.example

② Realm 发现

获取 Realm 的 Authority 信息

2

获取 Authority Descriptor:

GEThttps://realm.example/.well-known/actr
GEThttps://realm.example/.well-known/actr

200 OK (Authority Descriptor)

{
  "authority": "actr://realm.example",
  "services": {
    {"rel": "realms", "href": "https://realm.example/realm",
     "protocol": "actr-realm-profile/1"
  },
  "realm_signing_keys": { ... }
}
使用 realm_signing_keys

验证后续 Realm Profile 的签名

⑤ 安全校验

验证签名、完整性与类型

5

校验 .actr:

  • 校验 SHA-256（与 Profile 中一致）
  • 验证 Ed25519 签名（使用 Publisher 公钥）
  • 校验类型与兼容性（Actor Type / ABI / Manifest）

验证是否通过？

拒绝启动
